# MueblesPro

Página web de catálogo para MueblesPro, con diseño blanco y oro intenso.

## Abrir el sitio

Abre `` directamente en el navegador o usa la extensión **Live Server** en Visual Studio Code y pulsa **Go Live**.

## Personalizar

- Cambia el número `573000000000` por el WhatsApp real del negocio en `index.html` y `script.js`.
- Edita productos, precios, descripciones e imágenes en el arreglo `products` de `script.js`.
- Los estilos están centralizados en `styles.css`.
